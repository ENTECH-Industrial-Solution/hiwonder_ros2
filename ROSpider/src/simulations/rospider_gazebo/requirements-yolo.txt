# here (opencv-python 5.0, ultralytics) is already installed to the user site,

# a launched node's path. So:
#
#   pip install --user --break-system-packages -r requirements-yolo.txt
#
# torch is NOT listed below, because which build you need depends on the GPU.
# The development machine has an RTX 5060, which is Blackwell (sm_120); the
# default PyPI wheel is not built for it and fails at the first CUDA call:
#
#   pip install --user --break-system-packages torch torchvision \
#       --index-url https://download.pytorch.org/whl/cu128
#
# CPU-only works everywhere and is much smaller, just slower. It is fine for
# inference in the simulator and painful for training:
#
#   pip install --user --break-system-packages torch torchvision \
#       --index-url https://download.pytorch.org/whl/cpu
#
# Set yolo_detect's `device` parameter to 'cpu' to force CPU inference.
